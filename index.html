Why Quorum

Most classroom quiz tools are cloud tools first, classroom tools second.

They're fast to set up because a vendor's server does the work for you — your roster, your answers, your internet connection. In a graded, in-person class, that's exactly the part you don't want outsourced.

Typical cloud quiz tool

  • Every roster details (name, roll number, etc.) and answer passes through a vendor's server you don't control.
  • Anyone with the link can answer from anywhere — there's no way to confirm who was actually in the room.
  • No internet in the room means no quiz, full stop.
  • Integrity signals, if present at all, are an afterthought bolted onto a tool built for trivia night.
  • "Proctoring" often means GPS location and IP tracking — privacy-invasive data a vendor now holds on every student.

Quorum

  • Everything lives in one database file on the instructor's own laptop. Nothing is sent anywhere, ever.
  • A rotating, time-boxed QR gates joining — it has to be scanned from inside the room, right at quiz time.
  • Runs entirely over classroom WiFi. No campus internet, no problem.
  • Proctoring that doesn't need your location: per-student shuffled options, tab-switch (including Circle to Search overlays), copy, and screenshot detection, and a report built for a human to review.
  • No GPS, no IP tracking. Just a roll number and a 6-digit PIN Quorum generates itself and emails ahead of time.

Integrity

Flags a human reviews — not a black box that fails a student.

Quorum raises the cost of cheating well past what a casual attempt survives. It doesn't pretend to catch everything, and it never auto-fails anyone.

  • Per-student shuffled options

    Every student sees their own question and option order, seeded deterministically — screenshots and "what's the answer to B?" stop working.

  • One question at a time, forward only

    No going back to change an earlier answer after comparing notes, and no skipping ahead to preview what's coming — the server only ever moves a student to the next question, never back.

  • Tab-switch, copy & screenshot detection

    The client reports when a student leaves the quiz tab, copies text, takes a screenshot, or records the screen. Even a focus-stealing overlay that never hides the page — Circle to Search — still trips the same detection. Logged per question, visible on the Integrity Report.

  • One report, built for a decision

    Every flagged student in one place, with a one-click "notify" and an always-available "mark not guilty" — the teacher decides, every time.

Security & architecture

Data sovereignty by architecture, not by policy.

There's no server to breach because there's no server beyond the laptop already in your hand. Rosters, PINs, scores, and raw logs all live in one file, on one machine, that you control.

One honest exception: delivering each student's registration PIN by email is an administrative step that uses the internet — done between classes, never during one.

Pace vs. accuracy · Quiz 7

Straight answers, including the uncomfortable ones.

What happens if the internet goes down mid-quiz?
Nothing happens, because the quiz was never using it. Registration, joining, answering, and grading all run over the instructor's laptop and the classroom WiFi alone. The one exception is emailing PINs ahead of class — purely administrative, never during a session.
Can students cheat?
We won't claim it's impossible — no self-reported signal is unspoofable against a truly determined, technical student. What Quorum does is raise that bar far past a casual attempt: shuffled per-student options defeat "what's the answer to B," a rotating join QR defeats answering from elsewhere, and tab-switch/copy/screenshot detection — including focus-stealing overlays like Circle to Search that never actually hide the page — surfaces anything suspicious for the teacher to review and decide on, not an algorithm to silently penalize.
What if a student doesn't have a smartphone?
Scanning the rotating QR with a phone (or our iOS app) is what proves physical presence. We're also rolling out a short, typeable code as a laptop-only alternative for labs where phones aren't practical — ask us where that stands for your rollout.
Who actually owns the exported data?
You do, entirely. Rosters, scores, and integrity logs live in one local file you can back up, export to CSV/DOCX, or delete at any time. We never hold a copy.
